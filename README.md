# Cryptology Labs

Репозиторій містить лабораторні роботи з дисципліни «Основи
криптології».

Павліченко Катерина\

## Лабораторні роботи

### Лабораторна робота №1

Реалізація алгоритму шифрування IDEA.

Містить: - базові операції (mod 65537, mod 2\^16) - генерацію
підключів - шифрування та дешифрування блоку

### Лабораторна робота №2

Реалізація хеш-функції Adler-32.

Містить: - обчислення контрольної суми - тестування

## Як запустити

    python idea.py
    python adler32.py
